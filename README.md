# Tunnel Vector

A first-person browser racing prototype about wireframe geometry, momentum, and tunnel-to-tunnel jumps.

## Run locally

- `npm install`
- `npm run dev`
- Open the local URL printed by Vite.

## Controls

- Left / Right arrows or A / D: steer
- Up arrow or W: throttle
- Down arrow or S: brake
- Escape: pause / resume

The interface is in English. The first run is a single-player desktop/laptop experience, with a motion-reduced option and sound toggle.
